# 미디어로 중복 가려내기

파일 이름·글 번호·본문이 달라도 **미디어가 같으면** 같은 콘텐츠다.
아래 값들은 전부 실측이다 (스레드 요리 글 33편, 무관한 짝 481개).

## 네 겹을 함께 쓴다

| 겹 | 무엇을 잡나 | 도구 |
|---|---|---|
| ① 바이트 해시 | 파일이 통째로 같음 | `node:crypto` |
| ② 그림 해시 | 형식·크기만 바뀜 | `sips` (맥 기본) |
| ③ 가운데 해시 | 잘라냄 | `sips` / `ffmpeg` |
| ④ 소리 해시 | 화면을 잘라냄 | `ffmpeg` |

하나가 놓쳐도 다른 것이 잡는다. ①②③ 는 맥 기본 도구로 되고, 영상과 ④ 는 ffmpeg 이 필요하다.
**ffmpeg 이 없으면 그 겹만 조용히 놀게 만든다.** 통째로 죽이지 않는다.

## 실측값 — 짐작하지 말고 이 표를 봐라

| 상황 | 차이 (64비트 중) |
|---|---|
| 같은 사진, webp ↔ jpg | **2** |
| 영상 재인코딩 (crf 32, 절반 크기) | **1** |
| 영상 앞부분 잘림 | **0** |
| 10% 크롭 | 8 |
| 20% 크롭 | 16 ← 가운데 해시로는 **0** |
| 무관한 글 중 가장 가까운 짝 | **14** |
| 무관한 글 대부분 | 18~34 |

→ **문턱 8.** 진짜 중복(0~8)과 무관한 것(14~) 사이에 여유를 둔다.
소리는 39비트 중 문턱 4 (같은 영상 0, 다른 영상 17).

## 반드시 차이해시(dHash)를 써라

평균해시(aHash)로 재면 **파스타와 잔치국수가 4비트 차이**로 걸린다.
둘 다 "위 밝고 가운데 어둡고 아래 밝은" 흔한 음식 사진 꼴이라 구분이 안 된다.
차이해시로 바꾸면 같은 조합이 28비트로 벌어진다.

9×8 로 줄인 뒤 **오른쪽 이웃보다 밝으면 1** 로 적는다. 64비트가 나온다.
밝기 자체가 아니라 밝기의 *기울기* 를 보므로 전체가 밝거나 어두운 것에 안 흔들린다.

```js
export function 밝기로해시(값들, 너비 = 9, 높이 = 8) {
  if (!값들 || 값들.length !== 너비 * 높이) return null
  const 비트 = []
  for (let y = 0; y < 높이; y += 1)
    for (let x = 0; x < 너비 - 1; x += 1)
      비트.push(값들[y * 너비 + x] > 값들[y * 너비 + x + 1] ? '1' : '0')
  const 값 = 비트.join('')
  // 한 방향으로만 밋밋한 것은 아무 데나 걸린다. 지문으로 쓰지 않는다
  return /^0+$|^1+$/.test(값) ? null : 값
}
```

## 도구별 함정

**`sips` 는 webp 로 '쓰지' 를 못한다.** `-s format bmp` 처럼 출력 형식을 반드시 준다.
안 주면 `Can't write format: org.webmproject.webp` 로 죽는다.

**`sips` 에서 자르기(`-c`)와 줄이기(`-z`)를 한 번에 주면 안 된다.**
9×8 을 시켰는데 7×6 이 나온다. 두 번에 나눠 부른다.

**`ffmpeg` 은 8비트 회색 원시값을 그대로 뱉는다.** 파일을 거칠 필요가 없다.

```bash
ffmpeg -v error -ss 1 -i 영상.mp4 -frames:v 1 \
  -vf scale=9:8 -pix_fmt gray -f rawvideo -    # 72바이트가 나온다
```

## 크롭을 잡는 두 가지

**가운데 해시** — 내 미디어의 가운데 80% 를 미리 재 둔다.
남이 20% 잘라 올리면 그 사람 화면이 곧 내 가운데라 0비트로 맞는다.

**소리 해시** — 화면을 아무리 잘라도 소리는 안 바뀐다.
앞 20초를 8000Hz 홑소리로 줄여 마흔 칸의 세기를 재고, 이웃과 견줘 1/0 으로 적는다.

```bash
ffmpeg -v error -i 영상.mp4 -t 20 -ac 1 -ar 8000 -f s16le -
```

둘이 서로 보완한다. 소리는 영상만 되고, 가운데는 사진에도 된다.

## 지어내지 않는다

지문을 못 만들면 `null` 을 돌려주고 그 겹을 건너뛴다. **빈 지문으로 비교하지 마라** —
빈 값끼리는 늘 같아서 아무 글이나 다 막힌다.

한 색으로 꽉 찬 그림, 소리가 없는 영상도 마찬가지다. 걸러 낸다.

## 안 되는 것 — 미리 알아 둬라

**CDN 주소로는 못 가린다.** 같은 영상이라도 글마다 자산 번호가 다르다.
내려받은 뒤에야 지문을 만들 수 있다.

**남이 같은 것을 직접 만들어 새로 찍으면** 못 잡는다. 그리고 대개 그건 잡을 필요도 없다 —
다른 콘텐츠다.

**좌우 반전·큰 글씨 덮어쓰기는 아직 안 재 봤다.** 필요하면 재 보고 이 표에 더한다.

## 문턱을 정하는 법

짐작하지 마라. **무관한 짝들의 거리 분포를 재서** 가장 가까운 값 아래로 잡는다.

```
무관한 짝 481개 → 가장 가까운 것 14비트
진짜 중복      → 0~8비트
따라서 문턱 8 (여유 6)
```

이 분포는 소재마다 다르다. 음식 사진은 서로 닮아서 특히 좁다.
새 분야에 쓸 때는 **다시 재라.**
