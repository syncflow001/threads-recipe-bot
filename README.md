# 스레드 요리글 자동화

스레드에서 반응 좋은 요리 글을 찾아, **내 말투로 다시 쓰고**, 내 계정에 자동으로 올립니다.
계정을 꾸준히 키우는 것이 목적입니다.

```
스레드 검색 → 등급 매기기 → 미디어 받기 → 내 말투로 재구성 → 스레드에 발행
```

한 줄이면 끝까지 돕니다.

```bash
node --env-file=.env.local run.mjs 레시피 --받기 --재구성 --발행
```

기본값은 **5편을 들여다보고 그중 1편만 올리는 것**입니다.
고르는 순서는 등급이 높은 것부터입니다 — 플래티넘 → 골드 → 실버 → 브론즈.

올라가는 모양은 이렇습니다.

```
본문        사진·영상과 함께 내 말투로 쓴 4~5줄
 └ 답글 1   [광고]
            🍲 요리 이름
            🛒 준비물 (재료마다 분량 포함)
            👇 핵심재료를 권하는 한 줄
            👉 쿠팡 제휴 링크
            👉 쿠팡 제휴 링크  (똑같은 것을 두 줄)
   └ 답글 2  👩🏻‍🍳 만드는 법 1️⃣2️⃣3️⃣
            쿠팡파트너스 활동의 일환으로 … (대가성 문구)
```

**광고 표기와 대가성 문구는 링크가 붙을 때만 들어갑니다.** 링크가 없으면 둘 다 안 붙습니다.

---

## 필요한 것

- **macOS 또는 리눅스**
- **Node.js 24 이상** — [nodejs.org](https://nodejs.org) 에서 받습니다. `node -v` 로 확인합니다
- **스레드 계정**
- **OpenAI 계정** — 글을 다시 쓰는 데 씁니다. 글 한 편에 몇십 원 수준입니다

npm 으로 설치할 것은 **하나도 없습니다.** 바깥 라이브러리를 쓰지 않습니다.

## 설치

```bash
git clone https://github.com/<계정>/threads-recipe-bot.git
cd threads-recipe-bot
cp .env.example .env.local
node 설정.mjs
```

`설정.mjs` 가 **열쇠가 다 있는지 확인해 주고, 말투를 물어봐서 만들어 줍니다.**
네 가지만 답하면 됩니다.

## 열쇠 준비하기

`.env.local` 파일을 열어 채웁니다. `open -e .env.local` 로 열립니다.

> ⚠️ 열쇠 값은 **이 파일에만** 넣으세요. 채팅창·메신저·이슈에 붙여넣지 마세요.
> `.env.local` 은 깃에 올라가지 않도록 막아 뒀습니다.

### 없으면 안 되는 것

| 열쇠 | 어디서 받나 |
|---|---|
| `OPENAI_API_KEY` | [platform.openai.com](https://platform.openai.com) → API keys → Create |
| `THREADS_ACCESS_TOKEN`<br>`THREADS_USER_ID` | 아래 "스레드 토큰 받기" 참고 |

### 없어도 도는 것

| 열쇠 | 없으면 |
|---|---|
| `THREADS_COOKIE` | 등급이 `알수없음` 으로 나옵니다. 대신 공유수로 고릅니다 → [넣는 법](docs/사용법.md) §5-1 |
| `COUPANG_ACCESS_KEY`<br>`COUPANG_SECRET_KEY` | 제휴 링크 없이 글만 올라갑니다 |
| `BLOB_READ_WRITE_TOKEN` | 사진만 올라가고 영상은 빠집니다 |

### 스레드 토큰 받기

1. [developers.facebook.com](https://developers.facebook.com) 에서 앱을 만듭니다
2. 제품에서 **Threads API** 를 추가합니다
3. **이용 사례** 안에서 리디렉션 콜백 URI 를 `https://localhost/` 로 넣습니다
   (리디렉션·제거·삭제 **세 칸을 다 채워야** 저장됩니다)
4. 권한은 `threads_basic` · `threads_content_publish` · `threads_manage_insights` 를 켭니다
5. 앱 ID 와 시크릿을 `.env.local` 의 `THREADS_APP_ID` · `THREADS_APP_SECRET` 에 넣습니다
6. 아래를 실행하면 주소가 뜹니다. 브라우저에서 열어 승인하고, 돌아온 주소를 붙여넣습니다

```bash
node --env-file=.env.local threads-login.mjs
```

토큰은 **60일마다** 만료됩니다. 만료되면 이 명령을 다시 돌리면 됩니다.

## 처음 돌려보기

**아무것도 올리지 않고** 뭐가 잡히는지만 봅니다.

```bash
node --env-file=.env.local run.mjs 레시피
```

여기서 계정에는 아무 일도 일어나지 않습니다.
그다음 단계는 [docs/사용법.md](docs/사용법.md) 를 그대로 따라가면 됩니다.

## 옵션

| 옵션 | 하는 일 |
|---|---|
| (없음) | 검색해서 줄만 세웁니다. **아무것도 올리지 않습니다** |
| `--받기` | 사진·영상을 `media/받은것/` 에 내려받습니다 |
| `--재구성` | 내 말투로 다시 씁니다. 파일로만 저장합니다 |
| `--발행` | **실제로 스레드에 올립니다** |
| `TOP=5` | **몇 편을 들여다볼까** (기본 5) |
| `LIMIT=1` | **몇 편을 올릴까** (기본 1) |

키워드는 여러 개 넣어도 됩니다. `run.mjs 레시피 집밥 한식`

## 쓰기 전에 알아둘 것

**남의 글과 미디어를 가져다 씁니다.** 사진·영상을 그대로 내려받아 내 계정에 다시 올립니다.
저작권과 각 플랫폼 약관에 걸릴 수 있는 행위입니다. **판단과 책임은 쓰는 사람에게 있습니다.**
본문과 레시피는 LLM 이 다시 쓰지만, 미디어는 원본 그대로입니다.

**쿠팡 제휴 링크를 넣으면 광고 표기와 대가성 문구가 자동으로 붙습니다.**
`[광고]` 가 첫 답글 맨 앞에, `쿠팡파트너스 활동의 일환으로 일정액의 수수료를 제공받습니다` 가
레시피 맨 아래에 들어갑니다. **지우지 마세요.** 표시광고법상 필요한 표기입니다.

**로켓 상품만 고릅니다.** 로켓 배송 배지가 없는 상품은 링크로 쓰지 않습니다.

**스레드 한도가 있습니다.** 24시간에 게시물 250개, 답글 1,000개입니다.
한 편이 본문 1 + 답글 2~3 정도를 씁니다.

**통신을 가로채지 않습니다.** 브라우저 확장도, 자동 조작도 쓰지 않습니다.
공개된 문서를 두 번 요청하는 것이 전부이고, 발행은 스레드 공식 API 를 씁니다.

## 구조

| 파일 | 하는 일 |
|---|---|
| `src/threads.mjs` | 수집. 검색 문서에서 게시물을 뽑고, 상세에서 조회수와 글타래를 건집니다 |
| `src/score.mjs` | 등급. 조회 5,000 문턱을 넘긴 것만 좋아요÷조회수로 4등급 |
| `src/media.mjs` | 미디어 내려받기와 중복 방지 |
| `src/compose.mjs` | LLM 재구성. 본문·레시피 분할, 분량 대조, 링크 심기 |
| `src/coupang.mjs` | 쿠팡 상품검색 → 로켓만 → 제휴 링크 |
| `src/blob.mjs` | 영상을 공개 주소로 올립니다 (메타가 자기 CDN 영상을 안 받습니다) |
| `src/publish.mjs` | 스레드 발행. 450자 단위로 글타래를 잇습니다 |
| `run.mjs` | 위를 엮은 실행기 |
| `설정.mjs` | 처음 설정 도우미 |
