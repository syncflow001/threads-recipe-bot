# 스레드 요리글 자동화

스레드에서 반응 좋은 요리 글을 찾아 **내 말투로 다시 쓰고**, 내 계정에 자동으로 올립니다.
여러 계정을 브라우저 하나에서 돌립니다. **목적은 계정을 꾸준히 키우는 것**입니다.

```
홈 훑기 → 등급 매기기 → 사진·영상 받기 → 내 말투로 재구성 → 스레드에 발행
```

맥에서 돌아갑니다. `.command` 파일을 더블클릭하면 대시보드가 뜨고, 그다음부터는 브라우저에서 다 합니다.

---

## 5분 만에 띄우기

**필요한 것** — [Node.js](https://nodejs.org) 24 이상, 크롬, 스레드 계정.

```bash
git clone https://github.com/syncflow001/threads-recipe-bot.git
cd threads-recipe-bot
npm install
cp .env.example .env.local
```

그다음 **`설정화면 켜기.command` 를 더블클릭**합니다. 브라우저가 열리면서 대시보드가 뜹니다.

폰에서도 보려면 [Tailscale](https://tailscale.com) 을 깔고 **`설정화면 켜기 (아이폰에서도).command`** 를 쓰세요.
맥이 켜져 있는 동안 늘 돌게 하려면 **`설정화면 항상 켜두기.command`** 입니다.

첫 화면이 계정 만들기 마법사로 안내합니다. 터미널로 돌아올 일은 없습니다.

## 무엇을 하나

### 걷기

내 계정으로 **홈 피드를 훑습니다.** 검색이 아니라 홈인 이유는, 홈에 뜨는 글이
「지금 이 분야에서 퍼지고 있는 글」이기 때문입니다.

글마다 **확산 = 조회수 ÷ 팔로워** 를 재서 등급을 매깁니다 — 플래티넘 · 골드 · 실버 · 브론즈.
팔로워 5만 계정의 조회수 2만은 평범하지만, 팔로워 50 계정의 조회수 2만은 터진 글입니다.
등급은 **순서만 정합니다.** 좋은 것부터 쓰되, 좋은 게 없으면 그 아래라도 씁니다.

레시피는 본문이 아니라 **작성자가 자기 글에 단 답글**에 있습니다. 본문만 긁으면
재료도 순서도 없는 낚시글만 남습니다. 그래서 글타래까지 따라 들어갑니다.

같은 글을 두 번 쓰지 않도록 **사진·영상의 지문**으로 가립니다. 글자가 달라도 같은 영상이면
같은 콘텐츠입니다. 반대로 새로 찍었으면 다른 콘텐츠입니다.

### 다시 쓰기

`말투바탕.예시.json` 을 베껴 계정마다 말투를 정합니다. 정체성·자주 쓰는 표현·글 예시를
채우면 그 결로 글이 나옵니다. 대시보드에서 **말투를 대화로 만들어 주는 칸**도 있습니다.

원문을 베끼지 않습니다. 재료와 분량은 그대로 두고 문장만 내 말로 다시 씁니다.

### 올리기

스레드 공식 API 로 올립니다. 본문 하나에 답글 둘이 딸립니다.

```
본문        사진·영상과 함께 내 말투로 쓴 4~5줄
 └ 답글 1   [광고]
            🍲 요리 이름
            🛒 준비물 (재료마다 분량)
            👇 핵심 재료를 권하는 한 줄 + 제휴 링크
   └ 답글 2  👩🏻‍🍳 만드는 법 1️⃣2️⃣3️⃣
            대가성 문구
```

**[광고] 표기와 대가성 문구는 링크가 붙을 때만 들어갑니다.** 링크를 끄면 둘 다 안 붙습니다.

### 키우기

- **길들이기** — 홈 피드가 이 계정의 언어와 분야로 채워지도록 사람처럼 들락거립니다.
  외국어 계정에는 필수고(홈에 한국어만 뜨면 걷을 글이 없습니다), 한국어 계정에서도
  꾸준히 활동하는 계정으로 키우는 데 씁니다. 밤에는 안 돕니다.
- **하트·댓글** — 내 분야 글에 반응합니다. 초안을 만들어 두고 사람이 확인한 뒤 나갑니다.
- **팔로워·도달 재기** — 날마다 팔로워를 찍고, 내 글 조회수의 중앙값을 기준선과 견줍니다.
  스레드 API 는 과거 추이를 안 주므로 우리가 날마다 쌓습니다.

### 지켜보기

30분마다 **자동화가 제대로 도는지 스스로 점검합니다.** 예약이 사라졌는지, 판이 실패했는지,
성적을 안 재는 계정이 있는지. 이상이 **생기거나 고쳐질 때만** 텔레그램으로 알립니다.

점검기는 밖에서 흔적(로그·장부·예약)만 읽습니다. 그래야 「아예 안 떴다」를 잡을 수 있습니다 —
자동화가 스스로 신고하는 방식은 안 뜬 자동화를 못 잡습니다.

## 계정이 섞이지 않게

여러 계정을 한 컴퓨터에서 돌리면 **가장 무서운 사고는 A 계정 글이 B 계정으로 나가는 것**입니다.
되돌리기가 가장 어렵습니다. 그래서 문을 셋 세웠습니다.

**계정 하나 = 폴더 하나.** 계정에 딸린 것은 전부 그 안에 있습니다.

```
계정/example.cook/
  열쇠.env        persona.json     보관함.json
  활동장부.jsonl   팔로워장부.json    글성적장부.json
  도달기준선.json   점검기록.jsonl
  media/  (쓴것 · 받은것 · 막힌것)
```

1. **파일** — 계정 경로를 만드는 자리가 코드에 하나뿐입니다. 모듈이 제 손으로 이름을 조립하지 않습니다
2. **토큰** — 글을 올리기 전에 스레드에 **「이 토큰 주인이 누구냐」**를 묻습니다. 다르면 멈춥니다
3. **브라우저** — 쿠키를 심기 전에 같은 것을 묻습니다. 파일이 갈려도 브라우저가 남의 계정으로
   로그인돼 있으면 남의 홈을 길들이고 남의 글을 걷습니다

검사가 이 규칙들을 소스에서 직접 읽어 지킵니다. 어기면 빨간불이 납니다.

## 열쇠

두 갈래입니다.

| 갈래 | 어디 | 무엇 |
|---|---|---|
| **공용** | `.env.local` | 스레드 앱 · 쿠팡 · 텔레그램 · 블롭. 계정이 아니라 이 컴퓨터 주인의 것 |
| **계정 것** | `계정/<이름>/열쇠.env` | 토큰 · 사용자 번호 · 쿠키 |

`.env.example` 을 베껴 채우면 됩니다. 대시보드 「설정 → 열쇠」 칸에서 넣는 것이 더 쉽습니다.

발행 토큰은 **「자동발급」** 단추를 누르면 크롬이 열리고, 허용만 누르면 저절로 채워집니다.

> ⚠️ **공용 열쇠 사본을 계정 파일에 두지 마세요.** `node --env-file` 은 뒤에 오는 파일이 이깁니다 —
> 계정 파일에 사본이 있으면 그 계정만 딴 값을 씁니다.

## 검사

```bash
./검사.sh
```

이것 하나로 전부 돕니다. `node --test test.*.mjs` 는 쓰지 마세요 — 무늬가 `test.<이름>.mjs` 라
점 하나짜리 `test.mjs` 를 조용히 빼먹습니다. 그것을 모르고 「전부 초록」이라 믿었다가
계정 여덟의 발행을 죽일 버그 셋을 놓칠 뻔했습니다.

## 알아 두실 것

- **맥 전용입니다.** 예약은 launchd 를, 브라우저는 크롬을 씁니다
- **혼자 쓰는 도구입니다.** 로그인도 다중 사용자도 없습니다. 대시보드는 주소에 붙은
  열쇠말(`?k=…`)이 유일한 문이고, 그 안에 **이 컴퓨터에 아무 명령이나 내리는 터미널**이 있습니다.
  주소를 남에게 보이지 마세요. 밖에서 쓰려면 Tailscale 같은 사설망 안에 두세요
- **스레드가 바뀌면 걷기가 멈춥니다.** 통신을 가로채지 않고 공개 문서만 읽습니다.
  틀린 숫자를 보여주느니 빈칸을 둡니다
- **이 저장소에 계정 자료는 없습니다.** 이름은 전부 예시(`example.cook` · `sample_gohan` …)이고
  열쇠·장부·말투·사진은 하나도 들어 있지 않습니다
