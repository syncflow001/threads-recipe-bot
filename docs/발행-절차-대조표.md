# 발행 절차 대조표 — 계정마다 같은 길을 가는가

**2026-09-04 전수조사.** 사용자가 시켰다 — 「모두 동일한 방식을 지켜야 하잖아. 물론 참고하는 파일만 다를 뿐이지」.

계정을 새로 만들거나 「이 계정만 왜 다르지?」 싶을 때 여기부터 본다.
**절차를 새로 읽지 말고 이 표와 견준다.**

---

## 1. 발행 한 판의 순서 (코드에서 뽑은 정본)

### `자동발행.sh` — 문 여섯

| | 무엇 | 계정마다 다른 것 |
|---|---|---|
| 1 | 열쇠 파일 있나 확인. 없으면 그 판 끝 | `계정/<이름>/열쇠.env` |
| 2 | 열쇠 겹쳐 읽기 — 공용 먼저, 계정 것이 나중 (**뒤가 이긴다**) | `.env.local` → 계정 열쇠 |
| 3 | 팔로워 수 하루 한 번 찍기 (**멈춤보다 위**) | 계정 장부 |
| 4 | 전체 멈춤 확인 | 뿌리 `멈춤` |
| 5 | 계정 멈춤 확인 | `계정/<이름>/멈춤` |
| 6 | 마지막 발행 이후 `GAP_MIN` 분 지났나 | plist 가 넘긴다 (시각표에서 계산) |

그다음 `TOP=12 LIMIT=1 run.mjs --받기 --재구성 --발행` 을 부른다.

### `run.mjs` — 열여덟 걸음

```
 7 계정정보 → 분야·언어·제휴 → 팩 셋(분야·언어·제휴) 고르기
 8 persona.json 읽기 → 서식깔기 (형식 칸은 팩이 이긴다)
 9 보관함에서 꺼내기 (등급 순서. 좋은 것부터)
10 상세 채우기 — 못 읽으면 다른 계정 로그인을 빌린다 (src/읽기쿠키.mjs)
11 살아있나·쓸만한가 → 죽은 것은 보관함에서 뺀다
12 (보관함이 비면) 계정벽 → 크롬으로 홈 25번 스크롤
13 상세 채우기 (조회수 + 레시피 답글)
14 쓸만한가로 거르기
15 팔로워수 → 확산(조회수÷팔로워)으로 줄세우기 → 보관함에 담기
16 미디어 받기 → 사진 지문으로 겹친 글 거르기
17 볼거리있나·쓸만한가 다시 확인
18 토큰벽 — 이 토큰이 정말 이 계정 것인가 → 빠진 권한 확인
19 재구성(LLM, 감추기 없음) → 490자 넘기면 한 번 더 시켜 줄이기 → 별표 걷기 → 정체 모를 재료 줄 빼기
20 (2026-09-07 부터 없음 — 링크는 발행 때 안 넣는다. 터진 글에만 `늦은링크.mjs` 가 딴 답글로 단다)
21 재구성.json 안전쓰기
22 영상 갈아끼우기 → 관문 판정 → 막히면 막힌것으로 + 보관함에서 뺀다
23 글 올리기 (본문 → 레시피 답글 하나, 최대 480자. 「광고」 주제 태그는 링크가 있을 때만)
24 미디어 썼다표시 · 보관함에서 뺀다
```

⚠️ 2026-09-07 — 20번이 비었고 23번의 「광고」 태그가 늦은 답글로 옮겨 갔다. 위 표는 그날 이후의 순서다.
옛 순서(발행 때 링크 넣기)는 `docs/세션/2026-09-02_요리팩-전면개편.md` 에 있다.

⚠️ **본문과 답글은 다른 문으로 나간다.** 본문은 **API(토큰)**, 레시피 답글은 **브라우저(쿠키)** 다.
답글을 브라우저로 다는 까닭은 링크에 딸려 붙는 **미리보기 카드를 X 로 지우려고**다 —
공식 API 로는 못 끈다. 그래서 **토큰이 죽으면 본문부터 못 올리고, 쿠키가 안 먹으면 본문만 올라간다**
([[한-계정이-안-돌면-문마다-따로-재라]]).

## 2. 계정마다 같은가 — 넷을 쟀다 (2026-09-04)

**① 코드에 계정별 갈래가 없다.** 발행 길 여덟 파일(`run.mjs`·`자동발행.sh`·`compose`·`publish`·
`관문`·`팩`·`홈수집`·`보관함`)을 계정 이름으로 훑었다. **박힌 갈래 0개.**
갈리는 것은 오직 **분야·언어·제휴** 세 값이다.
(유일한 예외 — `run.mjs` 의 `계정이름 = 프로필 || 'example.cook'`. PROFILE 이 늘 주어져 안 쓰인다)

**② 열쇠 파일이 전부 깨끗하다.** 계정마다 `THREADS_COOKIE`·`THREADS_ACCESS_TOKEN`·`THREADS_USER_ID`
**셋만** 있다. 공용 열쇠 사본도, `SCROLL`·`REPLY_VIA`·`TOP`·`LIMIT`·`NOLINK` 같은 딴 값도 없다.
→ 한 계정만 딴 설정으로 도는 일은 없다.

**③ 실제 프롬프트 뼈대가 언어별 셋뿐이다.** 계정마다 프롬프트를 만들어 블록 차례를 대조했다.
한국어·영어·일본어로만 갈리고 **차례는 같다.**

**④ 형식 칸을 팩이 이긴다 — 전부 ○.** 계정이 팩 칸을 덮은 곳이 하나도 없다.

**⑤ 예약도 같은 것을 부른다.** 모든 plist 가 `/bin/bash 자동발행.sh <계정이름>`, 하루 5판,
같은 PATH·LANG, `RunAtLoad false`, 같은 작업 폴더다.

## 3. 그때 찾은 어긋남

- **`sample_lazy` 가 하루 5판 중 3판을 새벽에 올린다** — `00:15 · 02:21 · 04:00 · 11:09 · 15:21`.
  오후 4시 이후가 한 판도 없다. 한국어 계정이다.
  (영어 계정 셋의 새벽 판은 **미국 낮**이라 의도로 보인다 — 02:00 = 미 동부 정오)
  「자동 배정」이 간격 규칙에 밀려 시를 계속 올린 결과로 보인다
- **예약이 빠진 것** — `sample.unni` 길들이기 · `sample_yori` 성적 · `sample_morning` 성적
- **검색어 0개** — `sample_minimi` · `sample_morning` (다른 계정은 14~23개).
  길들이기가 「검색어로 찾아 들어가 가르치기」를 못 한다
- **제휴는 쿠팡인데 링크를 끈 계정** — `sample_effort` · `sample_yori` · `sample_minimi` ·
  `sample_morning`. 기본값이 `링크넣기: true` 이니 누가 껐거나 만들 때 그렇게 잡힌 것이다.
  일부러면 그대로 두면 된다 (영어 계정 셋은 제휴가 「없음」이라 자연스럽다).
  ⚠️ 2026-09-04 부터 **링크가 안 붙는 계정은 핵심재료도 안 감춘다** — 감춘 자리에 놓을
  링크가 없는데 감추면 읽는 사람이 못 만드는 레시피가 나가기 때문이다.
  「링크가 안 붙는다」는 스위치를 껐거나 제휴가 「없음」이거나 둘 중 하나다
  (`sample_gohan` 은 스위치가 켜져 있지만 제휴가 「없음」이라 여기 든다)
- **`sample_salim` 의 글 예시 ③이 `[대파닭구이 레시피]` 로 시작한다** — 예시는 LLM 이 결을 따라 하는
  자료라 대괄호 제목 버릇이 옮을 수 있다

## 4. 홈 피드가 요리로 차 있는가 (길들이기 기록)

**본문만 보고 재는 값이라 답글 문제와 무관하다.** 낮을수록 빈손 판이 잦다.

```
sample_table   43~71%
sample_gohan     24~74%
sample_momo      23~66%
sample_salim     3~54%
sample_dinner 19~41%
example.cook     15~31%
sample_lazy     10~28%
sample_minimi  10~23%
─────────────────────────
sample_effort     7~22%   ← 빈손 판이 자주 난다
sample_yori        8~12%   ← 답글까지 못 읽어 0편이었다
```

⚠️ **이 값은 실제 건짐률을 낮게 잡는다.** `sample_yori` 는 8~12% 인데, 남의 쿠키로 제대로 읽으니
홈 15편 중 3편(20%)이 쓸 만한 레시피였다. **사진으로 알아보는 레시피 글을 글자만으로는 못 센다.**

## 5. 다시 조사하려면

한 번에 도는 도구는 아직 없다. 그때 쓴 방법은 이렇다.

1. `계정목록()` 으로 돌면서 `정보()`·`계정팩()`·`프롬프트만들기()` 로 **실제 프롬프트를 만들어**
   블록 이름(`^\[…\]`)만 뽑아 견준다
2. `열쇠.env` 의 **키 이름만** 뽑아 견준다 (값은 절대 찍지 않는다)
3. `launchctl list` + `plutil -convert json` 으로 plist 를 견준다
4. 홈 요리 비율은 `logs/길들이기-<계정>-YYYY-MM.log` 에서 `요리 [0-9]*%` 를 뽑는다

> 도구로 남길지는 사용자가 아직 안 정했다 (`도구/계정대조.mjs` 후보).
