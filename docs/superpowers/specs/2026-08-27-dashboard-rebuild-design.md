# 대시보드 개편 설계 — Next.js 로 다시 짜고 엔진은 그대로 둔다

2026-08-27 · 사용자와 여섯 토막으로 합의한 것. 실행 계획은 `docs/superpowers/plans/2026-08-27-dashboard-rebuild-plan.md`.
진행 상황과 길 대조표는 `docs/대시보드-개편-진행.md`(다섯째 문서 — CLAUDE.md §5 에 등록되어 새 세션이 찾아 본다).

## 0. 사용자가 정한 원칙 넷

1. 대시보드를 구축하는 데 수단과 방법을 가리지 않는다.
2. 모든 의존성을 사용한다. (CLAUDE.md §2-6 「의존성은 둘뿐」은 이 설계로 갈아 쓴다.)
3. 사용자가 실제 사용할 때 오류 없이 작동해야 한다. **초록불은 완료의 증거가 아니다** — 사람이 누른다.
4. **현재 기능을 옮기는 작업은 옮기기만 한다.** 문구·계산·단추를 더하거나 고치지 않는다. 더하는 것은 이 문서가 「새로」라고 적은 것뿐이다.

```

├─ src/ run.mjs *.sh 장부 *.json      ← 엔진. 그대로
├─ dashboard/                          ← 새 대시보드 (Next.js)
│  ├─ app/(pages)/{overview,revenue,publish,activity,persona,history,monitor,check,settings,admin}/page.tsx
│  ├─ app/start/                        ← 첫 화면 + 마법사
│  ├─ app/api/…                        ← 옛 길 50개 + 터미널 8개. 이름 그대로 (/status → /api/status)
│  ├─ components/                      ← shadcn 부품 + 우리 카드
│  └─ lib/엔진.ts                       ← 엔진을 부르는 문 하나. src/ import 와 프로세스 띄우기는 여기서만
└─ archive/2026-08-27-옛-대시보드/       ← 설정화면.mjs · src/설정화면-*.mjs (git mv, 마지막 단계에서)
```

- **문.** `?k=열쇠말` 한 번 → 쿠키 → 모든 `/api/*` 가 본다. 아이폰(Tailscale) 그대로. 관리자 도구의 맥 비밀번호 문(dscl, 8시간 통행증) 그대로.
- **켜 두기.** launchd `com.threads.dashboard` 가 `next start` 를 돈다. 포트는 지금 것. `설정화면 켜기*.command` 셋은 안 바뀐다. 다른 launchd 는 손대지 않는다.
- **엔진 부르는 두 방식.** 읽기(장부·상태·수익)는 `import`. 일 시키기(발행·수집·활동·토큰·활동 걷기)는 프로세스를 띄우고 SSE 로 흘린다 — 지금 `/log`·`/progress` 모양.
- **언어.** 화면·API 는 TS. 엔진 `.mjs` 는 `any` 로 받는다. 엔진을 TS 로 바꾸지 않는다.
  주소 조각은 영문이다 — Next 16 이 한글 경로를 빌드하지 못한다 (2026-08-27 실측). 화면 글자는 한국어.
- **폰(390px).** 옆바는 가로로 미는 단추 줄, 카드 한 열, 표는 제 칸 안에서만 굴린다. HANDOFF 08-27 실측 규칙 그대로.

## 3. 첫 화면과 마법사

- 계정이 하나도 없으면 빈 화면에 **「스레드 자동화 시작하기」** 하나. 누르면 마법사. 계정이 있으면 바로 개요.
- 한 화면에 하나씩 묻기 · 건너뛰기 · 중간에 닫아도 이어 하기 — 지금 마법사 방식 그대로.

| 순서 | 단계 | 무엇 |
|---|---|---|
| 1 | 이 계정은 무엇인가 | 이름·분야·언어·별칭 (그대로) |
| 2 | 페이스북 앱 연결 (공유) | `THREADS_APP_ID`·`THREADS_APP_SECRET` + **「발급 매뉴얼」**. 있으면 건너뜀 |
| 3 | 스레드 계정 연결 | **「자동발급」**. 실패하면 손 붙여넣기 칸 |
| 4 | 텔레그램 연결 (공유) | 봇 토큰·채팅 번호 + 「시험 메시지」. 있으면 건너뜀 |
| 5 | 쿠팡 연결 | Access·Secret. 건너뛰기 가능 |
| 6 | 말투 넷 | 나를 한 줄로 · 어떻게 말하나 · 표현 · 글 예시 (추천 포함, 그대로) |
| 7 | 언제 올릴까 | **「자동 배정」** 기본. 손으로 고칠 수 있다 |
| 8 | 끝 | 요약 + 개요로 |

### 자동발급 (`src/토큰받기.mjs`)

1. `playwright-core` 로 맥 크롬을 `크롬프로필/<계정>/` 로 띄운다. 처음이면 사용자가 스레드에 로그인한다.
2. `threads.net/oauth/authorize…` 를 열고 돌아오는 `https://localhost/?code=…` 의 **주소만 읽어** 코드를 뽑는다. 페이지는 안 열려도 된다. 통신 가로채기가 아니다 (CLAUDE.md §2-1).
3. 이후는 `threads-login.mjs` 의 로직을 그대로 떼어 낸 함수 — 짧은 토큰 → 60일 토큰 → 권한 확인 → 계정 번호 확인(계정벽) → 열쇠 파일. 터미널 방식과 자동발급이 **같은 함수**를 쓴다.
4. 같은 창의 쿠키를 `THREADS_COOKIE` 에도 채운다.
5. `크롬프로필/` 은 `.gitignore`.

## 7. 검증과 순서

1. **길 대조표** — `docs/대시보드-개편-진행.md`. 옛 길 58개(아래 부록) 하나마다 새 길 · 옮김 · 사람이 누른 날짜. 다 차야 옛 대시보드를 `archive/` 로. 그 전엔 옛 것을 다른 포트에 켜 두고 견준다.
2. **검사** — `test.mjs` 의 대시보드 검사를 새 길로 옮기고, 새 부품 넷에 하나씩: 시각 배정(3분 규칙) · 자동발급(주소→코드, 열쇠 파일 쓰기, 크롬 안 띄움) · 업데이트(임시 폴더에서 보존 목록이 안 덮이는지) · 활동 알림(저장한 화면 조각 읽기). 엔진 검사는 안 건드린다.
3. **사람이 누르는 다섯** — 첫 화면→마법사 끝 · 자동발급 · 자동 배정→발행 켜기→실제 한 편 · 원격 연결(텔레그램 도착) · 자동 업데이트(시험 판 + 「지금 확인」). 이것 없이 끝났다고 적지 않는다.
4. **덩어리 여섯** (하나마다 커밋 + 인계 갱신) — ① 뼈대·문·옆바·빈 쪽·새 포트 launchd ② 그대로 쪽 일곱 옮기기 ③ 개요·활동 알림·판매 리스트 ④ 설정·마법사·첫 화면 ⑤ 관리자 도구·공개판 도구 ⑥ archive·포트 바꿔치기·문서.
