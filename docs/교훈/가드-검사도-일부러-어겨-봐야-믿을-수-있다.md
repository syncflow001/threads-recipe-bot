## 믿었던 것

「계정 경로는 `계정길()` 로만 만든다」를 지키라고, 소스를 읽어 규칙 어긴 줄을 찾는 검사를
만들었다. 초록이었다. **그러니 규칙이 지켜지고 있다**고 믿었다.

## 해본 것

검증 에이전트가 저장소를 임시 폴더에 사본으로 뜨고, 이미 고친 사고들을 **하나씩 되살려**
검사를 다시 돌렸다. 원본은 안 건드렸다.

## 나온 것

첫 판 검사는 **사고 셋을 그냥 통과시켰다.** 초록인데 규칙이 안 지켜지고 있었다.

무늬를 넓히고 보는 폴더를 늘린 뒤 다시 재니 —

| 심은 것 | 결과 |
|---|---|
| 손 안 댄 사본 | 초록 10 / 빨강 0 |
| 초안 경로를 뿌리에 조립 | **빨강 2** (두 검사가 이중으로 문다) |
| `run.mjs` 가 말투 이름 조립 | **빨강 1** |
| 자동발행이 옛 멈춤 자리 | **빨강 1** |
| 로그인이 옛 열쇠 자리 | **빨강 1** |
| 활동장부를 뿌리에서 읽기 | **빨강 1** |
| 전부 되돌림 | 초록 10 / 빨강 0 |

## 지금 결론

**초록인 가드 검사는 「규칙이 지켜진다」는 뜻이 아니라 「이 검사가 아무것도 못 봤다」는 뜻일 수도 있다.**
둘을 가르는 유일한 길은 **일부러 어겨 보는 것**이다.

가드 검사를 새로 만들면 그 자리에서 사본에 옛 꼴을 심어 빨간불을 확인한다.
빨간불이 안 되면 그 검사는 아직 없는 것과 같다.
