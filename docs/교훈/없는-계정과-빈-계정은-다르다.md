## 믿었던 것

`프로필읽기` 가 `팔로워: null` 을 주면 「못 읽었다」로 봤다. 갓 만든 계정도 그럴 수 있다고 생각했다.

## 해본 것

새 계정 `sample_noon` 이 세 판을 내리 실패했다. 같은 방법으로 프로필 문서를 받아
**실재하는 계정**과 나란히 견줬다.

## 나온 것

```
sample_lazy     801KB · <title> 「나른한저녁님(@sample_lazy) • Threads…」 · follower_count 있음 · 아이디 25번
sample_noon  257KB · <title> 그냥 「Threads」               · follower_count 없음 · 아이디  0번
```

- **257KB 짜리 껍데기에 제목이 그냥 「Threads」면 그런 아이디가 없는 것**이다
- 견줄 표본 — `sample_yori` 는 팔로워 0명·글 0편인데도 `follower_count` 가 **0 으로 나온다**.
  **비어 있는 계정과 없는 계정은 문서가 다르다**
- 토큰으로도 갈린다. 열세 계정 중 이 하나만 400 —
  `Session key is malformed because of invalid user id`
- 비슷한 아이디 넷(`lazy_afternoon`·`sample_noon_`·`lazyyafternoon`·`lazyy.afternoon`)도 없었다

## 지금 결론

**`팔로워: null` 을 「못 읽었다」로만 읽지 마라.** 「그 아이디가 없다」일 수 있다.
가르는 눈금 셋 — **문서 크기 · `<title>` 에 계정 이름이 있나 · 본문에 그 아이디가 몇 번 나오나.**

대시보드에 계정을 먼저 만들고 스레드 계정을 나중에 만들면 이 상태가 된다.
그때 발행은 판마다 실패하고 알림만 쌓인다.
