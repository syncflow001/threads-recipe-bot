## 믿었던 것
`launchctl unload` 만 하면 옛 plist 는 그 자리에 남으니 되살리면 된다.

## 해본 것
⑥ 바꿔치기 순서를 문서에 적고 최종 검토자가 단계를 하나씩 따라갔다.

## 나온 것
③ 「설정화면 항상 켜두기.command」 가 같은 경로에 새 plist 를 `cat >` 로 덮어쓴다. ②(unload)만 하고 ③을 하면 옛 plist 는 사라지고, 옛 `설정화면.mjs` 도 archive 로 가서 되돌릴 길이 없었다. 백업 단계(②-1)를 넣어 고쳤고 실제 바꿔치기 때 그대로 했다(`~/Library/LaunchAgents/옛/`).

## 지금 결론
되돌리기 안내를 쓰면 **각 단계가 무엇을 덮어쓰는지** 스크립트를 열어 확인한다. 「되돌릴 수 있다」는 백업 파일 경로를 적을 수 있을 때만 쓴다.
