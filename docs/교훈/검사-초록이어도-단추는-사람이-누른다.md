## 믿었던 것
빌드·검사가 전부 초록이면 화면 단추도 돈다.

## 해본 것
대시보드 개편 ⑤ 원격 연결 카드. 검사 규칙상 쓰기 길(`/api/remote/*`)은 검사에서 안 부른다. 최종 검토자가 코드를 읽어 잡았다.

## 나온 것
「크롬 원격 데스크톱 열기」 단추가 `부르기('/remote/open')` 를 몸통 없이 불러 GET 으로 나갔고, 길은 POST 만 있어 405 — 게다가 `catch {}` 가 삼켜 화면에 아무 말도 없었다. 검사는 전부 초록이었다. (⑤ 최종 검토 Critical 1, 고침 06b985c)

## 지금 결론
쓰기 길이 걸린 단추는 자동 검사가 안 누르므로 **사람이 눌러야 끝난다** — `CHECKLIST.md` 「사람이 눌러야」 표가 그 목록이다. `부르기(길)` 에 몸통을 안 주면 GET 이 된다는 것도 같이 기억한다(`dashboard/lib/api.ts`).

## 아직 모르는 것
쓰기 길을 가짜 서버(파일 안 쓰는 모드)로 눌러 보는 검사를 만들 가치가 있는가 — 지금은 단추가 스무 개라 사람이 누르는 쪽이 싸다.
