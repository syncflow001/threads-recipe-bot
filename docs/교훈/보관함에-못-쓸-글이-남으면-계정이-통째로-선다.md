## 믿었던 것

이 함정은 **이미 한 번 잡았다고 믿었다.** `run.mjs` 127~132줄에 큼직하게 적혀 있다 —
「보관함에 문턱 미만 한 편이 남으면 ①이 "쓸 것이 있다" 로 판단해 홈을 안 훑고,
그 뒤에 문턱이 그 한 편을 버려 0편으로 끝났다 … **다시 넣지 마라.**」
그래서 등급 문턱을 없앴고, 검사까지 세워 뒀다.

## 해본 것

사용자가 「오늘 글을 못 올린 계정들이 있다」고 했다. 계정 여덟의 오늘 판을 세었다.

```
sample.unni        판 3 · 올림 0 · 실패 3
sample_table       판 3 · 올림 0 · 빈손 3
sample_minimi      판 3 · 올림 0 · 빈손 3
sample_cooking   판 4 · 올림 2 · 실패 1
나머지 넷             전부 올림
```

## 나온 것

sample_table·sample_minimi 는 쿠키 건이었다 ([[토큰만-주인을-묻고-쿠키는-안-물었다]]).
**쟁여둔언니는 달랐다.** 판마다 똑같은 줄이 찍혔다.

```
쟁여 둔 글이 8개 있습니다 — 여기서 먼저 고릅니다
  … 7개 건너뜀 — 같은 그림을 N일 전 이미 올렸다
  쟁여 둔 것 가운데 쓸 만한 글 1개
  DciS7Fhk39o 막혔습니다 — 400ml(원글에 없던 분량이다)
‼️  이번 판이 실패했습니다
```

**같은 함정의 다른 얼굴이었다.** 등급 문턱은 없앴지만, 「영영 못 쓸 글」을 만드는 길이
두 개 더 있었고 둘 다 보관함에서 안 빠졌다.

| 길 | 다시 돌리면 달라지나 | 보관함에서 빠졌나 |
|---|---|---|
| 지문이 이미 올린 사진과 겹침 | **안 달라진다** (이미 올린 것은 계속 올린 것이다) | ❌ |
| 관문이 막음 (지어낸 분량 따위) | **안 달라진다** | ❌ — 주석에 「막힌 글은 쓴 글이 아니다」라고 일부러 안 뺐다 |

그 한 편이 「쓸 만한 글 1개」로 세어져 **홈을 안 훑는다.** 마지막으로 올린 것이 08-28 18:17,
그 뒤 네 판 연속 같은 자리에서 죽었다. 보관함은 14일이 지나야 저절로 빠지니
**열흘을 더 서 있을 참이었다.** sample_cooking 도 16:24 에 같은 꼴이었다.

## 지금 결론

**「다시 돌려도 결과가 안 바뀌는 글」은 보관함에서 뺀다.** 겹친 것도, 막힌 것도.
막힌 글은 `media/막힌것` 에 남으니 잃는 것이 없다.
`안겹친것만()` 이 버린 code 를 돌려주게 해서, 내려받기 실패 같은 **일시적인 것과 갈랐다** —
일시적인 것까지 빼면 다음 판에 되살아날 글을 버린다.

**규칙을 하나 없앴다고 그 함정이 사라진 것이 아니다.** 함정의 모양은 「못 쓸 글이 보관함에
남는다」이고, 등급 문턱은 그 모양을 만드는 **여러 길 중 하나**였을 뿐이다.
주석이 「다시 넣지 마라」로 끝나 있어서 그 길만 안 만들면 되는 줄 알았다.

## 아직 모르는 것

`안쓴것만()` 이 버리는 글(다른 계정이 이미 쓴 미디어)도 같은 성질일 텐데 이번엔 안 건드렸다.
쟁여둔언니 사례에서는 전부 「겹침」과 「막힘」이라 이 길로 물린 계정을 아직 못 봤다.
보관기간 14일이 후보를 오래 쥐고 있는 것이 맞는지도 다시 재 본 적이 없다.
