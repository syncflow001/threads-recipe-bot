## 믿었던 것

「이 길은 어차피 **거절될 것**이니 실서버에 한 번 보내 봐도 된다」고 짐작했다.
2026-08-27 대시보드 개편 ② 중, `test.대시보드.mjs` 의 「쓰기 거절 대조」가
`/keywords {검색어들:'x'}`(배열이 아닌 값)를 **새 서버뿐 아니라 옛 서버(7788, 사용자가 그때 실제로 쓰던 것)에도** 보냈다.

## 해본 것

계정 여덟이 들어 있는 실서버에 대고 검사 한 판.

## 나온 것

옛 `/keywords` 는 배열이 아닌 값을 **거절이 아니라 빈 목록으로 저장**했다.
게다가 옛 서버와 새 서버가 동시에 `계정정보.json` 을 읽고 쓰면서 **계정 항목 넷이 날아갔다.**

되살린 길은 APFS 로컬 스냅샷 하나뿐이었다 — 장부 파일(`*.json`)은 `.gitignore` 라 git 에 없다.

```
tmutil listlocalsnapshots /
mount_apfs -s <스냅샷이름> /System/Volumes/Data <붙일폴더>
```

14:44 판에서 `계정정보.json` 을 꺼내 되살렸다.

## 지금 결론

**검사는 실서버에 읽기 길만 보낸다. 쓰기 길은 임시 폴더(뿌리 인자)에서만 돌린다.**
「거절될 것」은 짐작이지 근거가 아니다 — 거절되는지 알고 싶으면 실서버에 보내지 말고 **옛 코드를 읽어서**
몸통 검사가 저장보다 앞서는지 확인해라. 장부를 만지기 전엔 `.백업-*` 로 복사해 둔다.

`CLAUDE.md` 「꼭 지킬 것」과 `HANDOFF.md` 대시보드 절에 규칙으로 박아 뒀다.
파일뿐 아니라 **시스템 예약(launchd)** 에도 같은 함정이 있다 —
[[검사가-진짜-launchd에-유령-예약을-남긴다]] 가 그 형제 카드다(2026-08-28, 같은 뿌리·다른 얼굴).
