## 믿었던 것
주제 달기가 실패하면 알리도록 붙였고, 검사도 초록이니 됐다고 믿었다.
판단은 한 줄이었다 — `!/달았다/.test(주제결과)`.

## 해본 것
커밋하기 전에 **실패 갈래 일곱을 만들어** 판단부만 돌려 봤다.
(정상 · 칸 못 찾음 · 후보 없음 · **던짐** · 광고 아닌 글 · API 통로 · 태그 없는 언어)

## 나온 것
```
✗ 던졌다   '못 달았다 — timeout'   → 안 알린다
```

**실패 문구가 「못 달았다 — …」라 그 안에 「달았다」가 들어 있다.**
부분일치로 보니 성공으로 읽혔다 — 하필 **가장 심한 실패(예외로 죽은 경우)만** 골라서 놓쳤다.

같은 자리에서 둘째도 나왔다. 알림 모듈은 **같은 종류를 여섯 시간 잠재운다.**
종류를 「주제못달았다-<계정>」으로 두면 **한 판에 여러 편을 올릴 때 두 번째부터 조용히 넘어간다.**
글번호를 종류에 넣어야 글마다 한 번씩 울린다.

## 지금 결론
**알림은 「붙였다」로 끝나지 않는다. 실패 갈래를 하나씩 만들어 실제로 울려 봐야 한다.**
검사는 내가 맞다고 믿는 모양만 본다 — 내가 「못 달았다」와 「달았다」가 부분일치한다는 것을
몰랐으니 검사도 그것을 안 봤다.

성공은 **통째로** 맞춘다 (`/^「.+」 달았다$/`). 부분일치로 성공을 판단하지 않는다.
반영 — `30b4005`. 알림 종류에 글번호를 넣고, 검사가 둘 다 못 박는다.

## 아직 모르는 것
- **아직 실제로 울린 적이 없다.** 판단부만 시나리오로 돌렸지, 진짜 발행에서
  주제 달기가 실패해 텔레그램이 온 적은 없다. 다음 판을 지켜봐야 한다
- 다른 알림들(조회수없음·헬스체크)도 같은 부분일치 함정이 있는지 안 봤다
