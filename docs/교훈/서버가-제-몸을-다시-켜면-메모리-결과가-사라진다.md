## 믿었던 것
긴 일의 결과는 `상태통.마지막결과` 로 화면이 받는다(토큰 자동발급이 그렇게 돈다).

## 해본 것
⑤ 자동 업데이트 `run` — 덮고 빌드하고 `launchctl kickstart` 로 대시보드를 다시 켠다.

## 나온 것
새 프로세스의 `상태통` 은 비어 있어 `/last-result` 가 `{없음}` — 성공해도 화면에 아무 알림이 없었다(⑤ 최종 검토 Important). ⑥ Task 5 에서 `onDone` 이 `/api/update` 의 파일 기록을 다시 읽어 시작 시각 이후 한 줄을 알림으로 띄우게 고쳤다.

## 지금 결론
프로세스를 넘어가야 하는 결과는 **파일**(`logs/업데이트기록.json`)에 적고 화면은 파일에서 읽는다. 메모리 통은 한 프로세스 안에서만 믿는다. 같은 이유로 `상태통.진행` 을 잠금으로 쓰지 않는다(④ 넘김 → ⑤ Task 1 의 `토큰도는중` 깃발).
