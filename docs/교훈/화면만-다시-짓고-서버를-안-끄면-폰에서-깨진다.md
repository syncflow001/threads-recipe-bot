## 믿었던 것

「빌드 통과」를 확인 도구로 썼다. `next build` 가 초록이면 화면도 멀쩡하다고 봤다.
검사가 끝난 뒤 서버를 안 껐다 켠 것은 **아무 일도 아니라고** 여겼다.

## 해본 것

원본 폴더에서 합치기가 되는지 보려고 `next build` 를 한 번 돌렸다. 서버는 안 건드렸다.
몇 분 뒤 사용자가 폰 화면을 보냈다 — **색도 글꼴도 없는 맨 글자.** 링크는 파란 밑줄,
카드도 옆바도 없고 「계정 읽는 중…」 「불러오는 중…」 에서 멈춰 있었다.

## 나온 것

```
서버 뜬 때 : Aug 28 19:28
빌드 한 때 : Aug 29 10:15   ← 서버보다 새것

/_next/static/chunks/0-7nd3vlxpc27.css   500
/_next/static/chunks/1fw8r3-p0-mwx.js    500
```

Next 는 조각 파일 이름에 **해시**를 넣고, 다시 지으면 옛 조각을 **지운다.**
돌고 있던 서버는 부팅할 때 읽은 **옛 이름**이 적힌 HTML 을 계속 내주는데
그 파일들은 이미 없다. 그래서 CSS 도 JS 도 통째로 못 받는다 —
**색이 빠진 게 아니라 아무것도 못 받은 것이다.**

자동 발행은 멀쩡히 돌고 있었다. 화면만 깨져서 더 헷갈렸다.
서버를 껐다 켜니(launchd 가 저절로 다시 띄운다) 그 자리에서 전부 200 으로 돌아왔다.

## 지금 결론

**짓기와 껐다 켜기는 한 몸이다.** 둘 중 하나만 하면 안 된다.
따로 하지 못하도록 `도구.화면다시짓기.sh` 를 뒀다 — 짓고 나서 반드시 서버를 껐다 켠다.
짓기에 실패하면 서버는 안 건드린다(지금 도는 화면이 멀쩡하니까).

**「빌드 통과」는 화면이 멀쩡하다는 뜻이 아니다.** 오히려 다시 지은 그 순간이
열려 있던 화면이 깨지는 순간이다. [[검사-초록이어도-단추는-사람이-누른다]] 의 형제다 —
그 카드는 「초록 ≠ 눌러 봄」이고, 이 카드는 **「초록 ≠ 지금 열려 있는 화면」** 이다.

## 아직 모르는 것

폰이 옛 HTML 을 얼마나 오래 들고 있는지는 안 재 봤다. 서버를 껐다 켠 뒤에도
새로고침을 해야 하는지, 저절로 낫는지 — 이번엔 새로고침으로 확인했다.
