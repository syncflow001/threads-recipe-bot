# 2026-09-02 — 요리팩 전면 개편 · 팩과 말투의 경계 · 광고 비율 조사

커밋 89개. 앞 세션에서 이어 하루 종일 요리팩을 실측대로 다시 짰다.

## 한 줄

**조사 문서를 팩에 반영했다고 믿었는데, 일곱 계정 중 여섯에 한 글자도 안 가고 있었다.**
계정 말투 파일이 팩을 덮고 있었기 때문이다. 그것을 고친 것이 오늘의 뼈대다.

## 한 일

### 1. 팩과 말투의 경계를 그었다 (사용자 결정)

| | 누가 정하나 |
|---|---|
| **문장 구조** — 본문 길이·글 흐름·도입 유형·레시피 형식/규칙/길이·지켜야 할 것·쓰지 말 것 | **분야 팩** |
| **말투** — 정체성·말투·이모지·자주 쓰는 표현·내 글 예시 | **persona.json** |

- `서식깔기` 를 뒤집었다 — **팩의 `말투서식` 이 가진 칸은 전부 팩이 이긴다.** 목록을 따로 안 적어서 팩이 칸을 늘리면 자동으로 따라간다
- 계정 파일 열에서 형식 칸 여섯을 뺐다. `말투바탕.json` 에서도 뺐다 (새 계정이 물려받는 것을 막는다)
- **자유 서술인 `말투` 칸이 진짜 문제였다.** 「본문 딱 3줄」(계정) 대 「본문 4~5줄」(팩)이 같은 프롬프트에 나란히 나가고 있었다. 열한 계정의 말투를 다시 써 어투·소재만 남겼다
- **이모지는 팩에서 계정으로 돌려줬다** — 이모티콘은 말투 쪽이다

### 2. 답글 모양을 실측대로 바꿨다

근거 — `docs/조사-제휴답글-형식.md` 146편 · `docs/조사-제휴링크-전수조사.md` 676편

### 3. 세 언어팩을 같은 자리에 세웠다

⚠️ 영어권 감추기는 **실측이 없다** — 한국·일본 실측을 옮긴 것이다. 제휴를 붙이기 전에 재야 한다 (CHECKLIST).

### 7. 실제 발행 샘플을 뽑아 봤다 (`--재구성`, 발행 안 함)

`example.cook` 로 끝까지 돌려 나온 답글이다.

```
🍰 노오븐 밥솥 카스테라

🛒 준비물
이것 300g                      ← 핵심재료(핫케이크 믹스)를 감췄다
🥣 이거 하나로 반죽 끝 🥣          ← 가림막 17자. 이름을 안 말한다
https://link.coupang.com/a/…
계란 3개                        ← 링크 뒤에 재료가 이어진다
우유 100ml
식용유 약간

👩🏻‍🍳 만드는 법
1️⃣ 볼에 계란 3개와 우유 100ml 넣고 거품기로 곱게 풀어.
2️⃣ 이것 300g 붓고 뭉침 없이 부드럽게 섞어.
https://link.coupang.com/a/…    ← 그 재료를 쓰는 단계에 같은 링크 한 번 더
3️⃣ 내솥에 식용유를 얇게 바르고 반죽을 다 부어.
…

쿠팡파트너스 활동의 일환으로 일정액의 수수료를 제공받습니다
```

**답글 340자 · 1조각 · 주소 2번 · 별표 0개 · 준비물에 「핫케이크 믹스」 안 보임.**
오늘 넣은 것이 전부 실제로 나왔다.

**돌려 보다 가려져 있던 결함을 찾았다** — `run.mjs` 가 `재구성.json` 을 `writeFile` 로
직접 써서 `--재구성` 만 돌리면 ENOENT 로 죽었다. 미디어를 안 받으면 폴더가 없기 때문이다.
실제 발행 판에서는 미디어를 먼저 받아 폴더가 생겨 있어 **한 번도 안 드러났다.**
`안전쓰기` 로 옮겼다. 검사가 같은 자리 **열 곳을 더 찾았다** — CHECKLIST 에 넣었다.

## 회고 — 오늘 무엇을 배웠나

**① 「고쳤다」와 「그 말이 닿는다」는 다른 사건이다.**
오늘의 절반은 **이미 고쳤다고 믿었던 것을 다시 고치는 일**이었다. 조사 문서를 팩에
반영해 놓고 일곱 계정 중 여섯에 안 갔다. 검사는 초록이었고 파일을 열면 새 값이 있었다.
사용자가 「전수 조사해서 보고하라」고 하지 않았으면 못 찾았다.
→ 앞으로 팩·설정을 고치면 **실제 프롬프트를 뽑아 본다.**

**② 초록불을 세 번 더 못 믿게 됐다.**
오늘 만든 검사 가운데 **넷이 처음에 헛통과**했다 — 옛 모양을 글자로 박아 둔 검사,
소스 전체를 봐서 딴 줄에 걸린 검사, git 이 한글 경로를 감싸 목록이 빈 검사, 시험 자료가
짧아 안 걸린 검사. **일부러 어겨 보지 않았으면 넷 다 몰랐다.**
→ 가드를 붙였으면 **반드시 어겨서 빨간불을 본다.** 이건 이제 습관이 아니라 규칙이다.

**③ 내가 낮에 넣은 지시가 저녁에 결함이 됐다.**
「만드는 법에서는 진짜 이름을 쓴다」를 내가 썼고, 그것 때문에 감춘 재료가 세 줄 뒤에
드러났다. 검수 에이전트가 실제 발행 글에서 찾았다.
→ **내가 방금 넣은 것도 검수 대상이다.** 새로 쓴 것일수록 더 그렇다.

**④ 표본을 어떻게 짰는지가 숫자를 정한다 — 또 겪었다.**
「쿠팡」 검색으로 모은 177곳의 광고율 75.3% 는 못 쓰는 숫자였다. 본문에 링크 박는
계정만 모였기 때문이다(93%). 편향 없는 홈 표본은 17.6% 였다.
이미 `본문-신호로-고르면-되는-글은-안-잡힌다` 카드가 있었는데도 **같은 함정에 다시 빠졌다.**
→ 카드를 쓰는 것만으로는 안 된다. **표본을 짜기 전에** 그 카드를 본다.

**⑤ 사용자가 나보다 자주 옳았다.**
「글 구조도 팩에서」·「이모지는 말투 쪽」·「별표 없애라」·「340자가 맞다」 — 넷 다
사용자가 짚었고 넷 다 맞았다. 특히 340자는 내가 360으로 올린 것을 되돌린 것이다.
→ 사용자가 **이미 재 둔 값**을 내가 다시 재려 할 때는, 먼저 그 기록을 찾는다.
