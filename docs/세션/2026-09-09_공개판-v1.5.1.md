# 세션 2026-09-09 — 공개판 v1.5.1 · 주인을 syncflow001 로 되돌린다

- 공개판을 냈다. 추적 파일 661개 중 481개를 옮기고 180개를 뺐다.
  열쇠 검사·이름 잔재 검사·공개판 검사 모두 통과.
- **`syncflow001` 정지가 풀린 것을 확인했다.** `syncflow001/threads-recipe-bot` 이
  09-08 23:16 까지 쓰이고 있었고, 이력도 v1.4.0(`10fd1ea`)까지 `kimleader` 사본과 같았다.
- 09-07 에 임시로 `kimleader` 로 옮겼던 것을 **전부 되돌렸다** — `src/업데이트.mjs` 의 `저장소`,

## 결정 (왜 그렇게 했나까지)
- **v1.5.0 을 다시 태그하지 않고 v1.5.1 을 냈다.** v1.5.0 은 이미 두 저장소에 태그로 나가 있다.
  이미 나간 태그를 밀어내는 것보다 한 판 더 내는 쪽이 되돌리기 쉽다.
- **판을 1.5.0 으로 잡았던 까닭** — v1.4.0 뒤에 들어간 것이 고침이 아니라 기능이다.
  쿠키 자동발급 단추(`src/크롬쿠키.mjs`)·프로필 링크·터미널 「멈추기」 단추.
- **`kimleader/threads-recipe-bot` 은 지우지 않았다.** 지우는 것은 되돌릴 수 없어 사용자가 정할 일이다.
