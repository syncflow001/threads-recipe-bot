### 이어서 (3) — 본문 [광고] 제거 · 답글 480자 (2026-09-02, `156e608`)

**사용자가 정했다.** 나는 「자동화가 실패하면 표기가 사라진다」고 우려를 말했고,
사용자가 빼기로 정했다. 그대로 따랐다.

| 무엇 | 값 |
|---|---|
| 한국어팩 `광고표기` | **`''`** (뺐다) |
| 광고 표시 | **답글 주제 태그 「광고」 하나뿐** |
| 답글 전체 한도(`글자한도`) | **490자** |
| 레시피 길이(팩) | **360자** |

**레시피가 360자인 까닭** — 답글 490자에서 덧붙는 것 약 128자를 뺀 값이다
(링크 두 번 74 + 대가성문구 32 + 한 줄 소개 17 + 빈 줄). 1자 단위로 재어 경계를 찾았다 —
**레시피 362자에서 답글이 딱 490자**가 된다. 여유 두 자를 두고 360 으로 잡았다.
**360자면 답글 488자로 하나, 365자면 493자로 쪼개진다.**

두 번 바로잡았다.
- 처음에 「레시피를 480자로」로 잘못 읽어 답글이 621자가 되는 것을 **시험이 잡았다.**
  사용자가 「답글 전체를 480자로」라고 바로잡아 주었다
- **줄 단위로 재면 340자로 나온다** — 재료 한 줄이 통째로 들어가서 12자 작게 잡힌다.
  글자 단위로 다시 재어 362자를 찾았다. **경계를 잴 때는 재는 눈금도 봐야 한다**

### 🔴 가장 크게 지켜봐야 할 것

**주제 달기가 실패하면 광고 표기가 아예 없는 글이 나간다.** 전에는 본문 `[광고]` 가
안전망이었는데 이제 없다.

- `브라우저로답글달기` 가 `주제결과` 를 돌려준다 (「달았다」 / 「주제 칸을 못 찾았다」 / 「후보에 없다」)
- **아직 이것을 알림으로 띄우지 않는다.** 다음에 할 일 — 발행 판에서 `주제결과` 가
  「달았다」가 아니면 텔레그램으로 알린다
- 검사(`test.mjs`)에 **「본문 표기도 주제 태그도 없으면 안 된다」**를 못 박아 두었다.
  둘 다 빠지는 사고는 검사가 막는다. 다만 **런타임 실패는 검사가 못 막는다**
