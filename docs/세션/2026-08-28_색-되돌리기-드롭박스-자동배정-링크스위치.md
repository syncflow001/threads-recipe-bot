# 세션 2026-08-28 — 색 되돌리기 · 드롭박스 폭 · 자동 배정 20분 · 제휴 링크 스위치

## 한 일

넷을 손봤다. 사용자가 화면을 보고 한꺼번에 시킨 것이다.

1. **색을 되돌렸다.** 새 대시보드의 `globals.css` 는 shadcn 기본값 그대로라
   채도가 0인 회색뿐이었다. `design-system/브랜드.md` §3 의 색을 그대로 옮겼다 —
   바탕 `#eef3f0` · 카드 흰색 · 으뜸색 민트 `#2f9e74` · 글 `#1f2a37`.
   어두운 판도 같은 민트 결로 새로 짰다. 옆바는 `bg-background` 에서 `bg-card` 로 바꿨다 —
   바탕이 민트가 되면서 옆바가 본문과 붙어 보였기 때문이다.
2. **계정 목록 폭을 1.5배로.** base-ui 의 `SelectContent` 는 기본이 `w-(--anchor-width)` 라
   목록 폭이 단추 폭과 같았다. 별칭이 길면 잘렸다. `w-[calc(var(--anchor-width)*1.5)]` 한 줄.
3. **자동 배정을 20분 간격으로.** `src/시각배정.mjs` 의 `최소간격분` 을 3 → 20 으로 올렸다.
4. **제휴 링크 넣기 스위치.** 설정 → 발행 시각 카드의 켜기/끄기 아래에 붙였다.
   끄면 그 계정은 쿠팡 링크도, 딸린 [광고] 표시와 대가성 문구도 안 넣는다.
5. **옆바 계정 카드에 「제휴 링크 ON/OFF」 줄**을 「자동 발행」 바로 아래 같은 모양으로 넣었다.
   여기서는 **보여 주기만** 한다 — 끄고 켜는 것은 설정 쪽 스위치 하나뿐이다.
   둘이 같은 자료(`/link`)를 보므로 스위치를 누르면 옆바가 바로 따라 바뀐다 (눌러서 확인했다).

## 결정 (왜 그렇게 했나까지)

- **링크 스위치는 새 기관을 안 만들었다.** `run.mjs` 에 이미 `NOLINK=1` 이라는 길이 있었다.
  계정정보.json 에 `링크넣기` 칸 하나를 더하고, `run.mjs` 가 그 값을 `NOLINK` 와 함께 본다.
  이렇게 하면 **부르는 길이 하나로 모인다** — 자동발행.sh 도, 대시보드의 빠른 실행도,
  손으로 돌리는 것도 다 같은 판단을 쓴다. bash 쪽은 한 줄도 안 고쳤다.
- **`분자리`(추천분 [2,17,32,47])는 그대로 뒀다.** 그건 새 계정에 권하는 분이지
  자동 배정이 아니다. 15분 간격이라 20분과 어긋나지만 사용자가 시킨 것은 「자동 배정 버튼」이고,
  건드리면 test.mjs 세 줄이 함께 흔들린다. 필요하면 따로 정한다.
- **계정 수정이 스위치를 되살리지 못하게 막았다.** `고침검사()` 는 별칭·분야·언어·제휴 넷만
  돌려준다. `정보쓰기()` 의 겹치기가 옛 값을 지켜 주는 구조라 지금은 안전한데,
  그게 우연이 아니라 규칙이 되도록 test.mjs 에 검사를 하나 넣었다.

  장부에 `링크넣기: false` 가 적히고 설명 글이 「링크 없이 올려요」로 바뀌는 것까지 봤다.
  계정 목록도 열어 단추보다 넓게 뜨는 것을 확인했다.
- 확인용으로 만든 임시 `계정정보.json` 은 지웠다. 이 갈래에는 실제 장부가 없다.

## 알게 된 것

1. **작업 사본에서 눌러 본 것은 사용자의 화면이 아니다.** 검사·빌드·직접 클릭까지 다 하고
   「다 했습니다」라고 했는데 사용자 화면에는 없었다. 7788 을 띄우는 프로세스의 작업 폴더가
   원본이었기 때문이다. 카드로 남겼다 → [[사본에서-됐다는-것은-사용자-화면에서-됐다는-뜻이-아니다]]
2. **브랜드 색은 새 화면으로 안 따라왔다.** `globals.css` 가 shadcn 기본값 그대로라 채도가 0이었다.
   문서(`브랜드.md`)는 멀쩡히 있었는데 옮긴 사람이 없었을 뿐이다. 게다가 그 문서 첫머리가
   **옛 파일을 가리키고 있어서** 아무도 안 따라갔다. 그 줄도 새 파일로 고쳐 적었다
   → [[화면을-갈아엎으면-브랜드-색이-조용히-사라진다]]
3. **차트 색만 살아남은 까닭.** `실적그림.tsx` 가 `#2f9e74` 를 코드에 직접 박아 뒀다.
   변수를 쓴 곳은 다 회색이 됐고 박아 둔 곳만 버텼다. 「변수로 빼는 것이 늘 안전한 것은 아니다」의 실례다
4. **끄개는 이미 있었다.** 제휴 링크 on/off 를 넣으려고 발행 경로를 뒤졌더니 `run.mjs` 에
   `NOLINK=1` 이 이미 있었다. 계정정보에 칸 하나 더하고 그 한 줄에 얹으니 **bash(`자동발행.sh`)는
   한 줄도 안 고쳤다.** 자동 발행·빠른 실행·손으로 돌리기 셋이 같은 판단을 쓴다
5. **base-ui `SelectContent` 의 기본 폭은 트리거 폭(`w-(--anchor-width)`)이다.** 목록이 단추만큼만
   넓어서 긴 별칭이 잘렸다. 이건 코드 주석에 남겼다 (계정고르개.tsx)
6. **켜고 끄는 자리는 하나만 둔다.** 옆바 딱지는 보여 주기만 하고 스위치는 설정 쪽 하나뿐이다.
   둘 다 누를 수 있으면 어느 것이 진짜인지 사용자가 헷갈린다
7. **`분자리`(새 계정에 권하는 분, 15분 간격)와 자동 배정(20분)이 어긋난다.** 사용자가 시킨 것은
   자동 배정 버튼이라 그대로 뒀다. 건드리면 `test.mjs` 세 줄이 함께 흔들린다 — 아래 다음 액션에 남긴다
