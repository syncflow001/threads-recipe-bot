# 세션 2026-09-07 — 레시피 답글 한도 340 → 480자

## 한 일
- 요리팩 셋(한국어·영어·일본어)의 「레시피 길이」를 **17줄·340자 → 20줄·480자**로 올렸다.
- 「레시피 규칙」에서 「짧게 적는다·요령을 덧붙이지 않는다·맺는 말을 넣지 않는다」를 풀었다.
  대신 **원글의 요령·주의점·대체 재료를 살리고**, 초보가 헷갈릴 자리(불 세기·순서의 까닭·어디까지 익히나)에
  옆에서 알려 주듯 한마디 곁들이라고 시킨다. **원글에 없는 시간·온도·분량 숫자는 지어내지 않는다** — 수량 검사가
  「추가됨」으로 잡는 것을 막기 위해서다.
- `src/compose.mjs` `재구성` — 레시피가 답글 한도(490)를 넘기면 **한 번 더 시켜 줄인다.** 그래도 넘으면 그대로 보낸다
  (쪼개진 글이 안 나간 글보다 낫다). 한도 안이면 한 번만 묻는다 — 값을 두 배로 쓰지 않는다.
- 검사 — `test.답글형식.mjs` ④를 480 으로 바꾸고 ④-1(한 번 더 시키기·한도 안이면 한 번만)을 더했다.
  `test.서식깔기.mjs` 의 세 언어 잣대를 480 으로 맞췄다. **32개 전부 초록.**
- 실제 프롬프트를 뽑아 열세 계정 모두에 「20줄·480자」와 요령 지시가 닿은 것을 봤다
  ([[고쳤다고-그-글이-닿는-것은-아니다]]).
- HANDOFF 「한눈에」의 340 문단을 480 으로 고쳤다.
- 대시보드 — 옆바·설정의 `@아이디` 를 누르면 스레드 프로필이 새 탭에서 열린다 (`components/공용/프로필링크.tsx`).
  화면을 다시 짓고 `com.threads.dashboard` 를 껐다 켰다. 헤드리스 크롬으로 눌러 새 탭을 확인했다.
  ⚠️ 열쇠는 뿌리 주소 `/?k=` 에서만 받고 쿠키를 심는다 — `/settings?k=` 로 바로 가면 「주소가 맞지 않습니다」다.
- **재부팅 뒤 전체 점검 (22시).** 예약 39개 전부 다시 실림 · 종료코드 이상 없음 · 멈춤 표시 없음 · 테일스케일 ·
  원격(Orca 6768) · 크롬 확장 연결 · 헬스체크 13계정 이상 없음 · 눈점검 13계정 전부 답글 읽음 · 점검상태 열린 문제 0.
  🔴 **찾은 것 하나 — 대시보드가 반쪽으로 떠 있었다.** 부팅 때 테일스케일 주소가 아직 안 붙어 `EADDRNOTAVAIL` 이 났는데
  Next 가 거부를 삼켜 `127.0.0.1` 만 열린 채 살아 있었다. 폰에서 못 열었다. `대시보드서버.mjs` 에 「없는 주소면
  5초씩 최대 5분 다시 묶기」를 넣고, 끝내 못 묶으면 죽어 launchd 가 다시 켜게 했다. 검사도 붙였다.
  부하(load 17~19)는 재부팅 뒤 스포트라이트 색인(mdworker)이라 곧 가라앉는다.

## 결정 (왜 그렇게 했나까지)
- **왜 480 인가.** 사용자가 정했다. 340 은 링크 37자 + 대가성문구 32자 + 가림막 30자를 답글 안에 함께 넣던 때의 값이다
  ([[한도는-덧붙는-것까지-세어야-한다]]). 2026-09-07 부터 링크는 발행 때 안 넣고 터진 글에만 **딴 답글**로 단다
  (`src/늦은링크.mjs` 가 `나누기` 로 제 조각을 따로 만든다). 레시피 답글에 덧붙는 것이 없으니 레시피가 곧 답글이다.
  스레드 한도는 글·답글 모두 500자다. `글자한도` 490 은 그대로 둔다.
- **왜 20줄인가.** 표본의 답글 하나는 중앙 408자·17줄이었다 — 한 줄 24자꼴. 480 ÷ 24 = 20.
- **왜 코드에서 한 번 더 시키나.** 340 때는 한도까지 150자가 남아 LLM 이 조금 넘겨도 한 조각이었다.
  480 은 10자만 남는다. LLM 은 「이내」를 곧잘 넘기고, 넘기면 답글이 둘로 쪼개져 조회수 0.62배다.
  [[지시는-부탁이고-코드가-약속이다]] — 어기면 글이 깨지는 규칙은 코드가 걷어내는 자리도 함께 만든다.
- **왜 두 번째에도 넘기면 그냥 보내나.** 발행을 막으면 판마다 0편이 될 수 있다
  ([[보관함에-못-쓸-글이-남으면-계정이-통째로-선다]]). 쪼개진 글이 안 나간 글보다 낫다.
- **자바스크립트 길이와 스레드 셈.** `나누기` 는 JS 길이(이모지를 여러 자로 셈)로 재므로 스레드 쪽 셈보다 늘 크다.
  그래서 490 도 실제로는 여유가 있다. 재는 눈금은 바꾸지 않았다 — 바꾸면 500 을 넘길 길이 생긴다.
- **뷰티팩은 안 건드렸다.** 「20줄 이내」로 글자 수가 없다. 링크도 요리와 같은 길을 타지만 요청 밖이다.
- **`링크넣기`·`감추기지시` 는 그대로 두었다.** 부르는 곳이 없고 검사만 남아 있다 — `archive/` 로 옮기는 것은 앞 세션의 남은 일이다.
