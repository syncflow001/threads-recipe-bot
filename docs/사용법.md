# 사용 설명서

스레드에서 잘 나가는 요리 글을 찾아, 내 말투로 다시 쓰고, 내 계정에 올려 주는 프로그램이다.

---

## 시작하기 전에 딱 두 가지

**터미널**을 씁니다. 맥에서 `Cmd + 스페이스` → `터미널` 이라고 치면 열립니다.

**모든 명령은 이 폴더에서** 칩니다. 터미널을 새로 열 때마다 한 번씩 쳐 주세요.

```
cd ~/projects/threads-recipe-bot
```

---

## 1. 제일 먼저 — 겁 없이 해봐도 되는 것

아무것도 올리지 않고, **뭐가 잡히는지만** 봅니다.

```
node --env-file=.env.local run.mjs 레시피
```

이런 게 나옵니다.

```
  레시피 → 21개
후보 21개 → 상위 10개만 상세 확인
알수없음   -   좋아요 1713  조회   -  공유 797  2장  비만클리닉 의사들이 강추하는...
알수없음   -   좋아요 1588  조회   -  공유 771  2장  이 레시피 만든 사람 누구냐...
```

여기까지는 **읽기만** 합니다. 계정에 아무 일도 일어나지 않습니다.

> **`조회`가 `-` 로 나오는 건 정상입니다.** 남의 글 조회수는 로그인 상태여야 보이는데,
> 지금은 대신 **공유수**로 줄을 세우고 있습니다. 잘 골라내고 있으니 걱정 안 하셔도 됩니다.

---

## 2. 글을 만들어만 보기 — 아직 안 올립니다

```
node --env-file=.env.local run.mjs 레시피 --받기 --재구성
```

- `--받기` : 영상·사진을 내 컴퓨터로 내려받습니다
- `--재구성` : 내 말투로 글을 다시 쓰고, 쿠팡 로켓 상품 링크를 찾아 붙입니다

만들어진 글이 화면에 뜨고, 파일로도 저장됩니다.

```
media/받은것/{글코드}/재구성.json
```

**마음에 들면 복사해서 손으로 올리셔도 됩니다.** 자동 발행이 부담스러우면 이 단계까지만 쓰세요.

---

## 3. 전부 자동 — 실제로 계정에 올라갑니다

```
TOP=1 node --env-file=.env.local run.mjs 레시피 --받기 --재구성 --발행
```

**`TOP=1` 은 "글 하나만"이라는 뜻입니다.** 처음에는 꼭 1로 해 보세요.

이렇게 올라갑니다.

```
본문        (사진 또는 영상 붙음)
 └ 답글 1   제목 + 🛒 준비물
   └ 답글 2  👩🏻‍🍳 만드는 법 + 쿠팡 링크
```

---

## 4. 조절할 수 있는 것

| 무엇 | 어떻게 | 설명 |
|---|---|---|
| 검색어 | 뒤에 그냥 나열 | `run.mjs 레시피 집밥 요리 한식` |
| 개수 | `TOP=3` | 몇 개를 깊이 볼지. 안 적으면 10 |
| 내려받기 | `--받기` | 빼면 영상·사진을 안 받습니다 |
| 글 다시 쓰기 | `--재구성` | 빼면 수집만 합니다 |
| 실제 발행 | `--발행` | **이게 있어야만 계정에 올라갑니다** |

`--` 붙은 것들은 **빼면 그 단계를 건너뜁니다.**

> `--env-file=.env.local` 은 열쇠 꾸러미를 읽어오는 부분입니다. **빼면 안 됩니다.**

## 5. 말투 바꾸기

가장 쉬운 방법은 설정 도우미를 다시 돌리는 것입니다. 네 가지만 물어봅니다.

```
node 설정.mjs
```

직접 고치고 싶으면 이렇게 엽니다.

```
open -e ~/projects/threads-recipe-bot/persona.json
```

텍스트편집기가 열립니다. 고치고 `Cmd + S` 로 저장하면 **다음 실행부터** 반영됩니다.

| 항목 | 뜻 |
|---|---|
| `정체성` | 내가 어떤 사람인지 |
| `말투` | 어떻게 말하는지 |
| `자주 쓰는 표현` | ㅋㅋ · ㅠㅠ 같은 것 |
| `글 구조` | 어떤 순서로 풀어가는지 |
| `쓰지 말 것` | 피하고 싶은 표현 |
| **`내 글 예시`** | **실제로 쓴 글. 이게 제일 강력합니다** |

> 설명을 열 줄 쓰는 것보다 **실제 내 글 한 편을 붙여넣는 게** 훨씬 정확합니다.
> 반응이 좋았던 글일수록 좋습니다. 두세 편이면 충분합니다.

## 5-1. 조회수·등급 켜기 (한 번만 하면 됩니다)

지금은 등급 칸에 `알수없음` 이 뜹니다. 스레드가 **로그인한 사람에게만 조회수를 보여주기** 때문입니다.
로그인 흔적(쿠키)을 한 번 넣어 주면 그때부터 조회수가 들어오고 등급이 제대로 나옵니다.
한 번 넣으면 보통 몇 달 갑니다.

1. 크롬에서 **threads.com 에 로그인된 상태로** 아무 글이나 엽니다.
2. 화면 아무 데나 **오른쪽 클릭 → "검사"**. 오른쪽에 개발자 창이 열립니다.
3. 그 창 위쪽 탭에서 **`Network`** 를 누릅니다.
4. 그 상태로 **⌘R** 로 새로고침합니다. 목록이 좌르륵 채워집니다.
5. 목록 **맨 위 항목**을 누릅니다.
6. 오른쪽 **`Headers`** 탭에서 아래로 내려 **`Request Headers`** 를 찾습니다.
7. **`cookie:`** 로 시작하는 줄의 **뒷부분 전체**를 복사합니다. 아주 깁니다. 중간에 잘리면 안 됩니다.
8. 터미널에 `open -e .env.local` 을 치면 편집기가 열립니다. 맨 아래 한 줄 넣고 저장합니다.

```
THREADS_COOKIE="여기에_붙여넣기"
```

> ⚠️ 이 값은 **내 스레드 로그인 그 자체**입니다. 가진 사람은 비밀번호 없이 내 계정에 들어옵니다.
> 대화창이나 메신저에 붙여넣지 마시고 이 파일에만 넣어 주세요.

확인은 이렇게 합니다.

```bash
node --env-file=.env.local run.mjs 레시피
```

- **됐으면** — 등급 칸에 `플래티넘`·`골드` 가 뜨고 조회수 숫자가 찍힙니다.
- **안 됐으면** — `⚠ 쿠키를 넣었는데 조회수가 안 온다` 라고 알려 줍니다. 7번을 다시 하시면 됩니다.

켜고 나면 달라지는 것입니다.

| 지금 | 켠 뒤 |
|---|---|
| 공유수 순으로 고름 | **좋아요 ÷ 조회수** 로 고름 |
| 등급 `알수없음` | 플래티넘 · 골드 · 실버 · 브론즈 |
| 조회 적은 글도 후보에 들어옴 | 조회 5,000 미만은 자동으로 빠짐 |

## 6. 알아두면 좋은 것

**같은 글은 두 번 안 올라갑니다.** 발행한 글은 `media/쓴것/` 으로 옮겨지고,
다음에 같은 글이 잡혀도 자동으로 건너뜁니다.

**레시피가 없는 글은 알아서 버립니다.** "순서는 영상 참고하세요" 같은 글은
재료도 순서도 없어서 아예 AI에 보내지 않습니다. 돈도 아낍니다.

**대가성 문구가 자동으로 붙습니다.** 쿠팡 링크 바로 앞에
"쿠팡파트너스 활동의 일환으로 일정액의 수수료를 제공받습니다" 가 들어갑니다. 법으로 필요한 문구입니다.

**로켓 상품만 고릅니다.** 로켓 배지가 없으면 아예 링크를 안 겁니다.
업소용·대용량(29,000원짜리 고추장 같은 것)도 걸러냅니다.

**돈이 드는 곳** — 글 한 편 쓰는 데 OpenAI 비용 몇 십 원, 영상 올릴 때 약간의 전송량.
지금 규모에서는 거의 안 듭니다.

## 7. 이럴 땐 이렇게

**⚠️ `원문 분량이 사라졌다` 경고가 떴어요**
AI가 `1스푼` 을 `1스푤` 처럼 잘못 쓰는 일이 가끔 있습니다. 그걸 잡아내는 감시입니다.
뜨면 올라간 글의 재료를 한 번 봐 주세요.

**⚠️ `링크 없음 — 로켓 상품이 없다`**
그 재료에 로켓 상품이 없다는 뜻입니다. 링크 없이 글만 올라갑니다. 정상입니다.

**⚠️ `THREADS_ACCESS_TOKEN 이 없다` / 발행이 401로 막혀요**
스레드 열쇠가 만료됐습니다. **60일마다 한 번** 갱신해야 합니다.
```
node --env-file=.env.local threads-login.mjs
```
화면 안내를 따라가면 됩니다. **다음 만료일 2026-10-17.**

**⚠️ `OpenAI 404` 또는 모델을 못 찾는다고 나와요**
모델 이름을 바꾸면 됩니다. `.env.local` 의 `OPENAI_MODEL` 을 `gpt-4o` 등으로 고치세요.

**⚠️ 글이 이상하게 나와요**
`persona.json` 의 `내 글 예시` 에 최근 잘 나온 내 글을 추가해 보세요. 가장 효과가 큽니다.

**아무것도 안 잡혀요**
검색어를 바꿔 보세요. 스레드 검색 결과는 시간대마다 달라집니다.

## 8. 잘 돌아가는지 확인하고 싶을 때

```
node test.mjs
```

`통과` 네 줄이 나오면 프로그램 자체는 멀쩡합니다.

> 다만 **이게 통과해도 실제로 잘 올라간다는 보장은 아닙니다.**
> 진짜 확인은 `--발행` 으로 한 번 올려서 눈으로 보는 것입니다.
