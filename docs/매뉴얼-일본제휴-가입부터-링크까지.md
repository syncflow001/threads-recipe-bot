# 매뉴얼 — 일본 제휴 두 곳, 가입부터 링크까지

조사일 2026-08-30. **각 회사 공식 도움말·규약을 직접 읽고 적었다.** 확인 못 한 것은 「확인 필요」로 표시했다.
읽기 좋게 만든 보고서 판: https://claude.ai/code/artifact/563941d1-1f16-4269-af44-91ec11ef7ca5

돈을 실제로 손에 쥐는 문제(은행 계좌·환전)는 [일본-수익화-조사.md](일본-수익화-조사.md) 에 따로 있다. **이 문서는 「어떻게 가입하고 어떻게 링크를 다느냐」만 다룬다.**

## 0. 먼저 알아야 할 것 — 두 곳은 시작 시점이 다르다

| | 라쿠텐 | 아마존 재팬 |
|---|---|---|
| **심사** | **없다.** 등록하면 바로 링크를 만든다 | 있다. 180일 안에 3건이 팔려야 정식 승인 |
| **지금 시작되나** | **된다** | **아직 아니다** — 계정에 글 10개, 팔로워가 어느 정도 쌓인 뒤 |
| 링크 붙일 곳 | Threads 는 공식 인정 SNS | 계정을 매체로 등록 |
| 요율 | 2~4% (상점이 최대 20%까지 올릴 수 있음) | 식품·음료 2% · 홈/키친 4% |
| 한 건 상한 | **1,000엔** | 없음 (2024-08-07 폐지) |
| 성과 유효기간 | 클릭 후 30일 | 장바구니 24시간 · 구매 89일 |

**그래서 순서는 라쿠텐 먼저다.** 심사가 없으니 오늘 가입해서 오늘 링크를 달 수 있다. 아마존은 계정이 자란 뒤에 신청한다.

## 1. 라쿠텐 어필리에이트 — 오늘 바로 된다

### 1-1. 준비물

- 이메일 주소 하나
- Threads 계정 주소 (예 `https://www.threads.com/@sample_gohan`)
- 라쿠텐 회원 아이디 (없으면 아래 1-2 에서 만든다)

일본 은행 계좌도, 일본 주소도 **가입에는 필요 없다.** 돈을 받을 때만 벽이 있다 (1-8).

### 1-2. 라쿠텐 회원 만들기

1. https://www.rakuten.co.jp 오른쪽 위 **「新規登録」** 을 누른다.
2. 이메일 주소를 넣으면 그 주소로 **인증 코드**가 온다.
3. 코드를 넣고 비밀번호와 이름을 넣는다. **이름은 로마자**로 넣어도 된다.
4. 끝. 이게 라쿠텐 회원 아이디다.

> 화면이 전부 일본어다. 크롬이면 주소창 오른쪽 번역 아이콘을 눌러 한국어로 바꿔 놓고 하면 편하다.

### 1-3. 어필리에이트 등록

1. https://affiliate.rakuten.co.jp 에 **라쿠텐 회원 아이디로 로그인**한다.
2. 이용 규약에 동의한다.
3. 끝이다. **심사가 없다.**

### 1-4. Threads 계정을 매체로 등록 ⚠️ 이걸 빼먹으면 규약 위반이다

라쿠텐은 **링크를 붙일 곳을 미리 등록**하게 한다. 등록 안 한 곳에 붙이면 위반이다.

1. 어필리에이트 화면에서 **マイページ**(마이페이지) → **サイト情報の登録**(사이트 정보 등록)
2. **＋サイトを追加登録する**(사이트 추가 등록) 를 누른다
3. 두 칸만 채우면 된다.
   - **運営サイト名** — 계정 이름 (예 `ズボラごはん`)
   - **運営サイトURL** — Threads 계정 주소
4. 아래 장르 선택은 **비워도 된다.**

### 1-5. 상품 링크 만들기 — Threads 는 「짧은 주소」를 쓴다

1. 어필리에이트 화면 위 검색칸에 상품 이름을 넣어 찾는다
2. 상품 옆 **商品リンク作成**(상품 링크 작성) 을 누른다
3. 링크 종류가 여럿 나온다 — **短縮URL**(짧은 주소) 을 고른다
4. `https://a.r10.to/xxxxxxx` 꼴의 짧은 주소가 나온다. 이걸 복사한다

> **왜 짧은 주소인가.** 기본 링크는 HTML 코드라 Threads 에 못 붙인다. 그리고 원래 주소는 아주 길다.

### 1-6. 글에 붙이는 법

```
와… 이거 진짜 편해요.
집에서 만드는 데 10분도 안 걸림 🍳

▼여기서 확인
https://a.r10.to/abcd1234

#PR 楽天アフィリエイトリンクを含みます
```

**PR 표기는 법으로 정해진 의무다.** 일본은 2023년 10월부터 스텔스 마케팅 규제(景品表示法)가 시행 중이고, 2026년 현재도 소비자청 단속이 활발하다. `#PR` `#広告` `#アフィリエイト` 중 하나를 **눈에 띄는 곳**에 넣는다.

### 1-7. 절대 하면 안 되는 것 — 걸리면 계정 정지 + 보수 몰수

| 금지 | 왜 |
|---|---|
| **남의 글 댓글·답글에 링크** | 규약이 콕 집어 금지. **내 글의 내 댓글은 된다** |
| DM·라인 등 개인 메시지에 링크 | 금지 |
| 등록 안 한 곳에 링크 | 1-4 를 안 하면 전부 위반 |
| 인정 SNS 밖에 링크 | 인정 SNS 는 열: Instagram · X · YouTube · 楽天ROOM · TikTok · Pinterest · Lemon8 · Facebook · **Threads** · moflog |
| 내 링크를 내가 클릭·구매 | 자기 구매 금지 |
| PR 표기 없이 올리기 | 규제 위반 |

> 라쿠텐이 2026년 2월에 「Threads 에서 위반이 특히 늘었다」는 공지를 냈다. 우리 계정이 표적이 되기 쉬운 자리라는 뜻이다.

### 1-8. 돈은 어떻게 되나 — 여기가 벽이다

| 월 보수 | 받는 방법 | 조건 |
|---|---|---|
| ~3,000엔 | 楽天ポイント (포인트) | 없음 |
| 3,001엔~ | 楽天キャッシュ | **본인 명의 라쿠텐 카드 또는 라쿠텐 은행 필수** |
| 은행 입금 | 현금 | 「国内の口座のみ」 — 일본 국내 계좌만 |

**한국 거주자는 라쿠텐 카드·라쿠텐 은행을 못 만든다.** 그래서 **월 3,000포인트가 사실상 상한**이다.
포인트는 楽天市場 에서 물건 사는 데 쓰고, Rakuten Global Express 로 한국에 받을 수 있다.

자세한 것과 우회로는 [일본-수익화-조사.md](일본-수익화-조사.md) §2·§3 에 있다.

### 1-9. 자동화 — 우리 프로그램에 붙이는 길이 있다

라쿠텐은 **공개 API 가 어필리에이트 링크를 직접 준다.** 쿠팡 팩과 같은 구조를 만들 수 있다.

- 신청: https://webservice.rakuten.co.jp — 라쿠텐 회원으로 앱 등록 → `applicationId` 발급
- 상품 검색 API 에 **`affiliateId` 를 함께 보내면** 응답에 **`affiliateUrl`** 이 들어온다
- 즉 「재료 이름 → 상품 검색 → 어필리에이트 주소」가 코드로 한 번에 된다

⚠️ **확인 필요** — 요청 한도 숫자가 공식 문서에 안 적혀 있다. 「같은 주소를 너무 자주 부르면 한동안 응답을 멈춘다」고만 적혀 있다.

## 2. 아마존 재팬 어소시에이트 — 계정이 자란 뒤에

### 2-1. 신청 전에 갖춰야 할 것

| 조건 | 값 | 근거 |
|---|---|---|
| 계정에 글 | **최소 10건** | 공식 — 「しかるべき量のオリジナルコンテンツ」 |
| 팔로워 | 공식 숫자 없음. **500명 전후에 통과한 사례**가 여럿 | 체험담 (공식 문구는 「일정 수의 오가닉 팔로워」) |
| 180일 안에 | **3건 판매(발송 완료까지)** | 공식. 못 채우면 계정이 닫힌다 |

**3건이 팔린 뒤에야 아마존이 사람 눈으로 심사한다.** 가입 직후는 「가승인」 상태다.
자기 구매·가족 구매는 3건에 안 들어간다.

### 2-2. 가입 절차

1. https://affiliate.amazon.co.jp → 아마존 재팬 계정으로 로그인 (없으면 만든다)
2. **계정 정보** — 이름은 **로마자**, 주소는 **한국 주소** 그대로
3. **매체 등록** — Threads 계정 주소를 넣는다
4. **미국 세무 정보(米国税務情報)** — 「미국 납세자가 아니다」 로 답한다
   > ⚠️ 이걸 빠뜨리면 **약 30%가 미국 세금으로 빠진다.** 반드시 한다
5. **일본 세무 정보(인보이스)** — 납세지 **한국**, **免税事業者**(면세사업자) 로 고른다
6. **지급 방법** — 해외 거주자는 **기프트권만** 된다 (최소 500엔)

> 스위스 거주자가 실제로 이 절차로 등록해 쓴 기록이 있다. 한국 주소도 같은 구조다.
> 사업자번호 칸이 나오면 사장님 개인사업자 번호를 넣는다.

### 2-3. 링크 만들기 — SiteStripe

가입하면 아마존 사이트 맨 위에 **어소시에이트 툴바(SiteStripe)** 가 뜬다.

1. 아마존 재팬에서 소개할 상품 페이지를 연다
2. 화면 맨 위 툴바에서 **リンク作成**(링크 작성) → **テキスト**(텍스트)
3. `https://amzn.to/xxxxxxx` 꼴 짧은 주소가 나온다. 복사한다

**손으로 만드는 법** (프로그램이 쓸 형식):

```
https://www.amazon.co.jp/dp/[ASIN]/ref=nosim?tag=[내아이디]-22
```

- `ASIN` = 상품 페이지에 적힌 10자리 상품 번호
- `tag` = 내 어소시에이트 아이디. **일본은 끝이 `-22`** 다

> ⚠️ **그냥 상품 주소를 붙이면 수수료가 0이다.** 반드시 `tag=` 가 들어가야 한다.

### 2-4. 글에 붙이는 법 + 필수 문구

아마존은 **규약이 정한 문장**을 넣게 한다. 이건 PR 표기와 별개다.

```
Amazonのアソシエイトとして、[계정 이름]は適格販売により収入を得ています。
```

Threads 글마다 넣기 어려우면 **프로필 소개란**에 넣어 두는 방법을 쓴다 (⚠️ 확인 필요 — 아마존이 SNS 프로필 표기를 인정하는지 명시 문구를 못 찾았다).
PR 표기(`#PR`)는 일본 법이 따로 요구하는 것이라 **둘 다** 필요하다.

### 2-5. 요율 (2026-02-18 개정)

| 분야 | 요율 |
|---|---|
| 비디오 대여·구매 | 10% |
| Kindle · 패션 | 8% |
| **홈 · 키친 · 가구 · 뷰티 · 드러그스토어** | **4%** |
| 완구 · 스포츠 · 베이비 | 3% |
| **식품 · 음료 · 주류** · 가전 · PC | **2%** |
| 기프트카드 | 0% |

요리 계정이면 **재료(식품 2%)보다 조리도구(키친 4%)가 두 배**다. 링크를 어디에 걸지 정할 때 쓸 숫자다.

### 2-6. 성과 유효기간

- 클릭 후 **24시간 안에 장바구니**에 담기면 성과로 잡힌다
- 장바구니에 담긴 뒤 **89일 안에 구매**하면 인정
- **한 건 상한은 없다** (2024-08-07 폐지)

### 2-7. 자동화 — 조건이 붙는다

아마존도 상품 API(PA-API)가 있지만 **문턱이 있다.**

- 어소시에이트 **심사 통과가 먼저**다
- **최근 30일 안에 매출이 있어야** 계속 쓸 수 있다. 없으면 호출이 에러로 돌아온다
- 처음엔 초당 1회. 최근 30일 발송 매출 $0.05 마다 하루 한도가 1씩 늘어난다

**그래서 처음에는 API 없이 간다.** ASIN 만 알면 2-3 의 주소 형식으로 링크를 만들 수 있다.

## 3. 두 곳을 같이 쓸 때

- **한 글에 링크는 하나.** 스레드는 밖으로 내보내는 글을 싫어한다 — 링크가 늘수록 도달이 떨어진다
- **어느 쪽을 걸까** — 라쿠텐은 한 건 1,000엔 상한이 있지만 상점이 요율을 20%까지 올리기도 한다. 아마존은 상한이 없다. **같은 물건이면 요율을 비교해 높은 쪽**을 건다
- **PR 표기는 어느 쪽이든 무조건.** 일본 법이다
- **댓글 링크는 라쿠텐이 금지.** 우리 방식(레시피 답글에 링크)은 **내 글의 내 댓글**이라 괜찮지만, 남의 글에는 절대 안 된다

## 4. 지금 할 일 — 순서대로

- [ ] ① **라쿠텐 회원 가입** (1-2). 10분
- [ ] ② **어필리에이트 등록** (1-3). 심사 없음
- [ ] ③ **Threads 계정을 매체로 등록** (1-4). ⚠️ 이걸 빼먹으면 전부 위반
- [ ] ④ 상품 하나로 **짧은 주소를 만들어 본다** (1-5). 형식을 눈으로 확인
- [ ] ⑤ 그 링크를 넣은 글을 **손으로 한 번 올려 본다.** PR 표기 포함
- [ ] ⑥ **라쿠텐 API 신청** (1-9) — 자동화의 입구
- [ ] ⑦ 계정 글이 10개 넘고 팔로워가 붙으면 **아마존 신청** (2-2)
- [ ] ⑧ 아마존 가입 직후 **미국 세무 정보**부터 처리 (2-2 ④). 안 하면 30%가 날아간다
- [ ] ⑨ **180일 안에 3건** — 여기가 계정 생존선

**프로그램 쪽에서 할 것.** `src/제휴/` 에 라쿠텐 팩을 만든다. 쿠팡 팩과 같은 자리에 끼운다.
④가 끝나 링크 형식을 눈으로 확인한 뒤에 시작한다 — 짐작으로 만들지 않는다.
